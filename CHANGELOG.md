# Changelog

## 1.0.1 - 2026-05-25

- Added the current session count to the menu bar label.
- Added a Settings window with General and About sections.
- Added an Open at Login setting.
- Refined the menu layout by moving Force Delete All into the session header and adding a compact settings button.

## 1.0.0 - 2026-05-25

- Initial release of Zellij-Sweep.
- Added menu bar session listing.
- Added session pinning to prevent accidental deletion.
- Added delete and force-delete actions for Zellij sessions.
- Added bulk force-delete for unpinned sessions.
